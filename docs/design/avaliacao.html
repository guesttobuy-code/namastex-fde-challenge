O laço fecha aqui: um erro marcado no Rastreio carrega a proveniência (decisão, regra aplicada, de onde veio o texto, que dados usou). A correção vira caso rotulado nesta régua — e, se o agente repetir o erro, o teste fica vermelho. Erro que não vira caso é erro que volta.
